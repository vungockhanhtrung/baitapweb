Kỹ năng & Công cụ đang rèn luyện

Các kiến thức nền tảng tích lũy qua học phần Thiết kế Web và Triển khai hệ thống phần mềm (FIT4014).

HTML5 & Semantic

  • Xây dựng khung trang chuẩn ngữ nghĩa (header, nav, main, section, footer).
  • Tối ưu khả năng truy cập (Accessibility) và form có ràng buộc dữ liệu.

CSS3 & Responsive

  • Áp dụng Box Model (border-box), biến CSS (Design Tokens).
  • Dàn trang linh hoạt với Flexbox, CSS Grid và tư duy Mobile-first.

Git & Triển khai

  • Quản lý phiên bản cục bộ bằng các lệnh Git cơ bản và gắn Tag phát hành.
  • Đưa website tĩnh lên môi trường thực tế qua GitHub Pages.
